# S3 (Simple Storage Service)

S3 is AWS object storage. Use it for backups, static assets, static websites, build artifacts, and logs.

---

## 1. Create a Bucket

### Console

1. **S3 → Create bucket**
2. Set **Bucket name** (globally unique): e.g. `my-app-assets-2024`
3. Select **Region**
4. Leave **Block all public access** on (unless hosting a static site)
5. Click **Create bucket**

### CLI

```bash
aws s3api create-bucket \
  --bucket my-app-assets-2024 \
  --region ap-south-1 \
  --create-bucket-configuration LocationConstraint=ap-south-1
```

---

## 2. Upload Files

```bash
# Upload single file
aws s3 cp myfile.txt s3://my-app-assets-2024/

# Upload with prefix (folder)
aws s3 cp myfile.txt s3://my-app-assets-2024/uploads/

# Upload entire directory (recursive)
aws s3 cp ./dist/ s3://my-app-assets-2024/dist/ --recursive

# Sync directory (only changed files)
aws s3 sync ./dist/ s3://my-app-assets-2024/dist/
```

---

## 3. Download Files

```bash
# Download single file
aws s3 cp s3://my-app-assets-2024/myfile.txt ./

# Download entire directory
aws s3 cp s3://my-app-assets-2024/dist/ ./dist/ --recursive

# Sync from S3 to local
aws s3 sync s3://my-app-assets-2024/dist/ ./dist/
```

---

## 4. List and Delete

```bash
# List buckets
aws s3 ls

# List objects in bucket
aws s3 ls s3://my-app-assets-2024/

# Delete single object
aws s3 rm s3://my-app-assets-2024/myfile.txt

# Delete directory
aws s3 rm s3://my-app-assets-2024/dist/ --recursive

# Delete bucket (must be empty first)
aws s3 rb s3://my-app-assets-2024

# Delete bucket and all contents (force)
aws s3 rb s3://my-app-assets-2024 --force
```

## 5. Static Website Hosting

```bash
# Enable website hosting
aws s3 website s3://my-app-assets-2024 \
  --index-document index.html \
  --error-document error.html

# Set public read policy
cat > public-read-policy.json <<EOF
{
  "Version": "2012-10-17",
  "Statement": [{
    "Sid": "PublicReadGetObject",
    "Effect": "Allow",
    "Principal": "*",
    "Action": "s3:GetObject",
    "Resource": "arn:aws:s3:::my-app-assets-2024/*"
  }]
}
EOF

# Disable block public access first (required for public site)
aws s3api put-public-access-block \
  --bucket my-app-assets-2024 \
  --public-access-block-configuration \
    "BlockPublicAcls=false,IgnorePublicAcls=false,BlockPublicPolicy=false,RestrictPublicBuckets=false"

# Apply policy
aws s3api put-bucket-policy \
  --bucket my-app-assets-2024 \
  --policy file://public-read-policy.json
```

Website URL: `http://my-app-assets-2024.s3-website.ap-south-1.amazonaws.com`

## 6. Versioning

```bash
# Enable versioning
aws s3api put-bucket-versioning \
  --bucket my-app-assets-2024 \
  --versioning-configuration Status=Enabled

# List versions of a file
aws s3api list-object-versions \
  --bucket my-app-assets-2024 \
  --prefix myfile.txt

# Restore specific version
aws s3api get-object \
  --bucket my-app-assets-2024 \
  --key myfile.txt \
  --version-id EXAMPLEVERSIONID \
  restored-file.txt
```

## 7. Presigned URL (Temporary Access)

Share a private object without changing permissions:

```bash
# Generate URL valid for 1 hour (3600 seconds)
aws s3 presign s3://my-app-assets-2024/private/report.pdf \
  --expires-in 3600
```

## 8. Lifecycle Policy (Auto-delete / Archive)

```bash
cat > lifecycle.json <<EOF
{
  "Rules": [
    {
      "ID": "delete-old-logs",
      "Status": "Enabled",
      "Filter": { "Prefix": "logs/" },
      "Expiration": { "Days": 30 }
    },
    {
      "ID": "archive-to-glacier",
      "Status": "Enabled",
      "Filter": { "Prefix": "backups/" },
      "Transitions": [{
        "Days": 90,
        "StorageClass": "GLACIER"
      }]
    }
  ]
}
EOF

aws s3api put-bucket-lifecycle-configuration \
  --bucket my-app-assets-2024 \
  --lifecycle-configuration file://lifecycle.json
```

## 9. Use in Jenkins (Artifact Upload)

```groovy
stage('Upload Artifact to S3') {
    steps {
        withCredentials([[
            $class: 'AmazonWebServicesCredentialsBinding',
            credentialsId: 'aws-credentials'
        ]]) {
            sh '''
                aws s3 cp target/app.jar \
                  s3://my-app-assets-2024/releases/${BUILD_NUMBER}/app.jar \
                  --region ap-south-1
            '''
        }
    }
}
```

## Storage Classes

| Class | Use Case | Cost |
|-------|----------|------|
| `STANDARD` | Frequently accessed | Highest |
| `STANDARD_IA` | Infrequent access | Lower |
| `GLACIER` | Archive, retrieval minutes | Very low |
| `GLACIER_IR` | Archive, retrieval seconds | Low |
| `DEEP_ARCHIVE` | Long-term, retrieval hours | Lowest |
